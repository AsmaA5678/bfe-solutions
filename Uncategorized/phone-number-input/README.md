# 10. phone number input

## Description
<p>Create a <code>PhoneNumberInput</code> component.</p>
<ol>
<li>only accepts numerical digits</li>
<li>format the number automatically as <code>(123)456-7890</code> by</li>
</ol>
<ul>
<li>adding the parenthesis when the 4th digit is entered</li>
<li>also adding <code>-</code> before 7th digit</li>
</ul>
<p>You can use the default text input without any styling.</p>
<h3>Follow-up</h3>
<p>What if user removes some digits in the middle, does caret jumps to the end in your approach?</p>
